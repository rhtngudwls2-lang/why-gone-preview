Microsoft Store 배포 종료일

Microsoft 3D Viewer

Microsoft 3D Viewer는 Windows에서 3D 모델 파일을 열어 살펴볼 수 있도록 만든 뷰어 앱입니다.

소개 근거 · 확인한 출처

3D Viewer for Windows가 여러 3D 파일 형식을 가져와 glTF로 변환해 렌더링하며 GLB를 권장한다고 설명한다.

원문 · support.microsoft.com

일부 Windows 10 기기에 사전 설치됐으며 Windows 11에는 사전 설치되지 않았음을 확인했다. 기존 설치본은 계속 작동한다.

원문 · learn.microsoft.com
